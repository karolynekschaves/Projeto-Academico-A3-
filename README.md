# Ideias Principal (sujeito a mudanças )

## Calcula a quantidade de CO₂ emitida 🚗🌳

### Lógica principal do programa:

- Entrada: Distância diária (km) e meio de transporte (Carro a gasolina, Moto, Ônibus, Metrô ou Bicicleta/Caminhada).
- Cálculo de CO₂: Aplica um fator de emissão médio por quilômetro percorrido.
- Conversão Ecológica: Converte o total de CO₂ acumulado no ano em número equivalente de árvores necessárias para absorver aquele gás.
- Comparador: Mostra quanto CO₂ a pessoa economizaria se trocasse 2 dias da semana por transporte público ou bicicleta.
